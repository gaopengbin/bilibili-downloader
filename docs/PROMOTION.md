### 前言

作为一个经常看 B 站的人，时不时会想把一些优质视频下载下来离线观看或者收藏。

于是就萌生了自己做一个的想法。虽然我不是专业开发者，但借助 AI（GitHub Copilot）的帮助，从零开始做出了这个工具。

折腾了一段时间，终于做出了一个自己满意的版本，开源分享给大家~

### 项目介绍

**B 站视频下载器** 是一个基于 Tauri 2 + Vue 3 + Rust 开发的桌面应用，主打一个**简洁好用**。

![screenshot](截图链接)

#### 为什么选择 Tauri？

说实话，技术选型也是 AI 帮我选的 😂

- **Tauri + Rust**：性能好，启动快，内存占用低
- **Vue 3**：前端框架，写界面方便
- **内置工具**：yt-dlp + aria2 + ffmpeg 全部打包进去，用户下载就能用

#### 核心功能

| 功能 | 说明 |
|------|------|
| 🎬 视频下载 | 支持单视频、分P、番剧、合集 |
| 📁 批量下载 | 收藏夹、历史记录一键下载 |
| 🔍 视频搜索 | 内置搜索，不用打开浏览器 |
| 🎨 清晰度选择 | 4K / 1080P / 720P / 480P / 360P |
| ⚡ 多线程加速 | aria2 多线程下载，跑满带宽 |
| 🔄 断点续传 | 下载中断可继续，不用重来 |
| 🌙 深色模式 | 夜猫子福音 |
| ⬆️ 自动更新 | 应用内一键更新 |

#### 技术栈

- **前端**：Vue 3 + TypeScript + Element Plus
- **后端**：Tauri 2 + Rust
- **下载核心**：yt-dlp + aria2 + ffmpeg（内置，无需额外安装）

### 一些开发感受

整个项目都是在 AI（GitHub Copilot）的帮助下完成的。

说几个感受：
1. **AI 写代码真的快**：描述需求，AI 就能生成代码，省了很多查文档的时间

3. **学到了很多**：虽然是 AI 写的，但看着代码也学到了不少 Rust 和 Vue 的知识

总的来说，AI 大大降低了开发门槛，让非专业开发者也能做出能用的工具。

**B 站视频下载器**，一个简洁好用的 B 站视频下载工具。

**下载地址**：https://github.com/gaopengbin/bilibili-downloader/releases

![软件截图](截图)

#### 功能特点

1. **开箱即用**：下载解压就能用，不需要安装 Python、FFmpeg 等环境
2. **界面友好**：现代化 UI 设计，支持深色模式
3. **下载快速**：多线程加速下载
4. **功能齐全**：
   - 支持单视频、分P视频、番剧、合集
   - 支持从收藏夹、历史记录批量下载
   - 支持 4K/1080P/720P 等多种清晰度
   - 支持断点续传

#### 使用教程

**第一步：下载软件**

前往 GitHub Releases 页面下载：
- 便携版（推荐）：`bilibili-downloader_x64_portable.zip`
- 安装版：`bilibili-downloader_x64-setup.exe`

**第二步：下载视频**

1. 复制 B 站视频链接
2. 粘贴到输入框，点击「获取信息」
3. 选择清晰度，点击「下载」

![操作演示](截图)

**第三步：登录账号（可选）**

点击左下角登录按钮，用 B 站 APP 扫码登录。

登录后可以：
- 下载 1080P 及以上清晰度
- 访问收藏夹和历史记录
- 下载部分需要登录才能看的视频

#### 常见问题

**Q：为什么只能下载 720P？**
A：这是 B 站的限制，未登录只能看 720P。登录后就能下高清了。

**Q：下载的视频在哪？**
A：默认在系统「视频」文件夹，可以在设置里改。

**Q：番剧为什么没有剧集？**
A：部分番剧需要登录后才能获取剧集，请先登录。
