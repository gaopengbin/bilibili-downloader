### 前言

市面上的下载工具要么需要安装 Python 环境，要么是网页版有各种限制，要么界面太丑陋……

折腾了一段时间，终于做出了一个自己满意的版本，开源分享给大家~

### 项目介绍

**B 站视频下载器** 是一个基于 Tauri 2 + Vue 3 + Rust 开发的桌面应用，主打一个**简洁好用**。

![screenshot](截图链接)

#### 为什么选择 Tauri？

- **性能好**：Rust 后端，启动快、内存占用低
- **原生体验**：使用系统 WebView，不额外捆绑浏览器
- **安全性**：没有 Node.js 运行时的各种安全问题

#### 核心功能

| 功能 | 说明 |
|------|------|
| 🎬 视频下载 | 支持单视频、分P、番剧、合集 |
| 📁 批量下载 | 收藏夹、历史记录一键下载 |
| 🔍 视频搜索 | 内置搜索，不用打开浏览器 |
| 🎨 清晰度选择 | 4K / 1080P / 720P / 480P / 360P |
| ⚡ 多线程加速 | aria2 多线程下载，跑满带宽 |
| 🔄 断点续传 | 下载中断可继续，不用重来 |
| 🌙 深色模式 | 夜猫子福音 |
| ⬆️ 自动更新 | 应用内一键更新 |

#### 技术栈

- **前端**：Vue 3 + TypeScript + Element Plus
- **后端**：Tauri 2 + Rust
- **下载核心**：yt-dlp + aria2 + ffmpeg（内置，无需额外安装）

### 一些技术细节

#### 1. 内嵌二进制文件

把 yt-dlp、ffmpeg、aria2 的可执行文件直接打包进应用，用户下载即可使用，不用折腾环境。

```rust
const YTDLP_BINARY: &[u8] = include_bytes!("../yt-dlp.exe");
const FFMPEG_BINARY: &[u8] = include_bytes!("../ffmpeg.exe");
const ARIA2C_BINARY: &[u8] = include_bytes!("../aria2c.exe");
```

#### 2. 多线程下载

使用 aria2 作为外部下载器，配合 yt-dlp 实现多线程下载：

```rust
"--external-downloader", "aria2c",
"--external-downloader-args", "aria2c:-x 16 -s 16 -k 1M"
```

#### 3. 进度解析

实时解析 aria2 和 yt-dlp 的输出，提取下载进度并通过 Tauri 事件发送给前端：

```rust
window.emit("download-progress-detail", progress_info);
```

#### 功能特点

1. **开箱即用**：下载解压就能用，不需要安装 Python、FFmpeg 等环境
2. **界面友好**：现代化 UI 设计，支持深色模式

4. **功能齐全**：

   - 支持从收藏夹、历史记录批量下载
   - 支持 4K/1080P/720P 等多种清晰度
   - 支持断点续传

#### 使用教程

**第一步：下载软件**

前往 GitHub Releases 页面下载：
- 便携版（推荐）：`bilibili-downloader_x64_portable.zip`
- 安装版：`bilibili-downloader_x64-setup.exe`

**第二步：下载视频**

1. 复制 B 站视频链接
2. 粘贴到输入框，点击「获取信息」
3. 选择清晰度，点击「下载」

![操作演示](截图)

**第三步：登录账号（可选）**

点击左下角登录按钮，用 B 站 APP 扫码登录。

登录后可以：
- 下载 1080P 及以上清晰度
- 访问收藏夹和历史记录
- 下载部分需要登录才能看的视频

#### 常见问题

**Q：为什么只能下载 720P？**
A：这是 B 站的限制，未登录只能看 720P。登录后就能下高清了。

**Q：下载的视频在哪？**
A：默认在系统「视频」文件夹，可以在设置里改。

**Q：番剧为什么没有剧集？**
A：部分番剧需要登录后才能获取剧集，请先登录。
